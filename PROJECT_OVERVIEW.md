\# Project Overview



Ich möchte eine moderne Fitness-Tracking-App entwickeln, die funktional an HEVY angelehnt ist.



Wichtig:

Die App soll NICHT kopiert werden. Sie dient lediglich als Inspiration hinsichtlich UX, Nutzerfluss und Featureumfang.



Ziel ist es, die bestmögliche Workout-Tracking-App zu entwickeln.



Die App soll:



\- extrem schnell sein

\- modern aussehen

\- sehr einfache Bedienung besitzen

\- langfristig erweiterbar sein

\- sauber nach Clean Architecture aufgebaut werden

\- skalierbar sein

\- wartbar sein



Die App soll zunächst als MVP entwickelt werden.



Erst wenn das MVP vollständig funktioniert, werden weitere Features ergänzt.



Arbeite immer nach diesen Prinzipien:



\- Clean Code

\- SOLID

\- DRY

\- KISS

\- Type Safety

\- Wiederverwendbare Komponenten

\- Trennung von UI, Business Logic und Data Layer
